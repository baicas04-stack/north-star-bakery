# North Star Bakery — Touchstone 3

This continues the four-page Touchstone Task 2 website. All pages share styles.css. The provided media folder must stay beside the HTML files. No JavaScript or backend is used.

## Open and preview

Open index.html locally, or open the repository in GitHub Codespaces and run:

```sh
python3 -m http.server 8000
```

In the Ports tab, open the forwarded port 8000 in your browser. Copy the actual preview URL. If instructor access is required, make the port public if your account permits it, and keep the Codespace running during review. Codespaces previews can stop working when the Codespace stops.

## Submission steps

1. Create or open your public GitHub repository.
2. Upload the four HTML files, styles.css, README.md, and media folder, preserving their paths. Upload the extracted contents, not just the ZIP.
3. Commit the files and verify the repository opens without signing in.
4. Start the Codespaces preview and check all four pages on a narrow and wide screen.
5. Paste your actual repository URL and preview URL into Casas_Bailey_Touchstone3.docx. Submit that completed document as instructed.

## Design

Four colors: cream #FFF8F0, brown #6B3E26, peach #D88C5A, charcoal #2F2A26. Georgia headings and Arial body text. Mobile-first Flexbox layouts switch at 48rem. The home page picture source changes at 700px.

Business details and prices are fictional samples. The form validates inputs and reloads contact.html; it does not deliver an order. Use dummy information only.
